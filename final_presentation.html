On-Policy vs Off-Policy Learning

On-Policy (PPO)

Learn from current policy's actions only

  • Collect data → Train → Discard data → Repeat
  • Like learning to drive by only using YOUR mistakes
  • More stable but sample inefficient
  • Training time: 4.1 hrs (slowest)
Trade-off: Stable updates, but wastes past experience

Off-Policy (SAC, TD3, DDPG)

Learn from ANY policy's past actions

  • Store all data in replay buffer → Reuse many times
  • Like learning from videos of ALL drivers
  • Sample efficient but can be unstable
  • Training time: 2.1-2.4 hrs (faster)
Trade-off: Efficient learning, but needs stability tricks

Theory → Observation Connection

Theoretical Prediction Why? Our Observation
Off-policy trains faster Reuses past experience via replay buffer TD3: 2.1 hrs vs PPO: 4.1 hrs (2x faster)
Off-policy can be unstable Learning from old, stale data can mislead DDPG unstable: -14.3% drawdown (no stability tricks)
TD3 > DDPG Twin critics + delayed updates fix instability TD3: 1.79 vs DDPG: 1.18 Sharpe (+52%)
On-policy more stable Always learns from fresh, relevant data PPO: Smoothest training curve, reliable convergence

Stochastic vs Deterministic Policies

Stochastic Policy (SAC, PPO)

Action = Sample from probability distribution

π(a|s) = N(μ(s), σ(s))
action = μ + σ × random_noise

  • Same state → Different actions each time
  • Built-in exploration (randomness)
  • Good for learning, uncertain environments
Trading: More trades (156/day), explores opportunities

Deterministic Policy (TD3, DDPG)

Action = Direct function of state

μ(s) = action
Same input → Same output (always)

  • Same state → Same action every time
  • Requires external noise for exploration
  • Good for execution, known patterns
Trading: Consistent execution, decisive (118 trades/day)

Theory → Observation Connection

Theoretical Prediction Why? Our Observation
Stochastic = more exploration Randomness discovers new strategies SAC: 156 trades/day (most active)
Deterministic = consistent execution No randomness → same decision every time TD3: 63.8% win rate (highest precision)
Deterministic better for exploitation Once pattern learned, execute confidently TD3: 1.79 Sharpe > SAC: 1.43 (+25%)
Stochastic = higher volatility Random actions introduce variance SAC: 0.105% vol vs TD3: 0.078% vol

Why Sharpe Matters More Than Returns

Sharpe Ratio = (Return - Risk-free Rate) / Volatility

SAC has highest return (0.15%) but highest volatility → Sharpe 1.43

TD3 has medium return (0.14%) but lowest volatility → Sharpe 1.79 (Winner!)

Key Research Insights

💡 Insight #1: Deterministic > Stochastic

TD3 (deterministic) beats SAC/PPO (stochastic). Trading rewards decisive, consistent execution over exploratory randomness.

💡 Insight #2: Patient Updates Win

TD3's delayed updates (d=2) prevent chasing noise. Wait for critics to stabilize before updating the actor.

💡 Insight #3: Conservative Estimates Matter

Twin critics reduce risk (TD3 -5.9% vs DDPG -14.3% drawdown). Taking min of two Q-values prevents overoptimistic trades.

💡 Insight #4: Trade Frequency Sweet Spot

118 trades/day (TD3) is optimal. Balance between capturing opportunities and avoiding overtrading costs.

💡 Insight #5: Modern Algorithms Exist for Reasons

DDPG (2015) fails catastrophically (Sharpe 1.18). Q-value overestimation + unstable training = TD3's improvements matter.

💡 Insight #6: Clipping Helps Stability, Not Returns

PPO has smooth training but not best test Sharpe. Clipped updates prevent exploration of optimal policies.

Key Takeaways for Practitioners

  1. Deterministic policies work better for trading - Consistent execution beats stochastic exploration
  2. Patient updates matter - Don't chase every market move, wait for confirmation
  3. Conservative value estimates reduce risk - Twin critics prevent overconfident trades
  4. Trade frequency has a sweet spot - ~120 trades/day balances opportunity and costs
  5. Modern algorithms exist for good reasons - DDPG's failure validates TD3's improvements
  6. Sharpe > Returns - 0.14% daily with low volatility beats 0.15% with high volatility
